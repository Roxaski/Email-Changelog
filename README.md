# Email-Changelog
I built a responsive changelog email template using Maizzle, Tailwind CSS and Vue.

## Requirements
[Node.js](https://nodejs.org/en) | v18.20 minimum.
[Git](https://git-scm.com/)

## Installation

Once you have the above installed, you'll want to open the folder where you want the project to stay and then run the following :

```bash
git clone https://github.com/Roxaski/Email-Changelog.git
cd Email-Changelog
npm install
```

## Dev Server

Next up you'll want to run the dev server (local host) within a terminal like git bash by running the following :

```bash
npm run dev
```

Open the local URL shown in the terminal in your browser in order for you to see what you're editing.
When you're finished, go back to the terminal and press CTRL + C to end the connection.

## Compilation

When your happy with the email's design and you're ready to compile it then run the following : 

```bash
npm run build
```
The compiled email is then saved to the dist folder.

## Documentation

If you're unsure about anything or need help with anything, then have a look through [Maizzle's Docs](https://maizzle.com/docs) as these are a great source to help you build your email templates.
